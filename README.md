# ファイブツアーズJET 漢字バトル 🚀✨

フジテレビ系人気番組「ネプリーグ」の「ファイブツアーズジェット」をオマージュした、小学校で学習する漢字を楽しく学べるWebタイピング・知育ゲーム（MVP）です。

👉 **ゲームプレイ（GitHub Pages）**: [https://fumiyan717.github.io/sisaku/](https://fumiyan717.github.io/sisaku/)

---

## 🎮 ゲームの特徴

1. **ファイブツアーズジェット風のSF演出**
   - 宇宙空間をハイスピードで進むジェット機（コックピット視点）
   - 迫り来るターゲットに表示される漢字の「よみ（ひらがな）」を入力
   - 正解するとレーザービーム発射＆派手な大爆発！
   - クルー（搭乗員5人＝ライフ）制。時間切れで1人ずつ撃墜！

2. **学年別コース制（1年生〜6年生＋全学年チャレンジ）**
   - **１年生コース**: 文部科学省学習指導要領配当の音読み・訓読みに100%完全準拠した基本の読み・送り仮名・数の数え方（全70問へ大幅拡充！）
   - **２年生コース**: 第2学年配当（160字）の漢字を使った日常の言葉（全40問収録）
   - **３年生コース**: 第3学年配当（200字）の漢字を使った身近な熟語（全40問収録）
   - **４年生コース**: 第4学年配当（202字）の漢字を使った発展の言葉（全40問収録）
   - **５年生コース**: 第5学年配当（193字）の漢字を使った少し高度な熟語（全40問収録）
   - **６年生コース**: 第6学年配当（191字）の漢字を使った総仕上げレベル（全40問収録）
   - **全学年チャレンジ**: 1年生〜6年生の全範囲からバランス良く出題される完全制覇ツアー
   - ※各学年で習っていない未習漢字が出ないよう、学習指導要領配当漢字に厳密に準拠！

3. **小学生にやさしい操作・入力システム**
   - **文字ブロック入力パネル**: 候補の平仮名10文字からポンポン押して直感解答（濁点・半濁点・促音・拗音も直接タップ可能）
   - **50音ソフトキーボード**: タブ切り替えで自由入力も可能
   - **マス目表示**: 何文字の読みか一目で分かるマス目スロット
   - **安心の制限時間30秒**: ゆっくり考えて答えられるゆとり設計
   - **PCキーボード完全対応**: `jyu`（じゅ）、`zyu`、`tyu`（ちゅ）、`syo`（しょ）、`kya`（きゃ）などの拗音・促音（っ）・撥音（ん）や、IME日本語入力に完全対応

4. **新機能「漢字の部屋（学習進捗コレクション＆全学年音訓カード）」🏛️✨**
   - 小学校6年間で学習する配当漢字全1,026字を学年ごとに一覧表示！
   - ゲームで正解した漢字がエメラルド色に光り輝く！
   - **漢字詳細カード（全学年タップ表示）**: 1年生〜6年生の全1,026字すべてで、漢字をタップすると音読み・訓読み・学年・正解回数（習得状況）を即座にポップアップ表示！
   - **学年別 音読み・訓読み一覧表**: 1年生〜6年生の各学年タブごとに、公式音訓一覧表（表形式）をモーダル内でいつでも閲覧可能！
   - 学年別・全体の進捗バーで「覚えた漢字の数と割合」を一目で確認可能
   - 児童一人ひとりの端末の **ローカルストレージ（localStorage）** に進捗データを自動蓄積・永続化
   - 必要に応じて進捗のリセットも可能

5. **ピュアWeb Audio APIサウンド**
   - 外部音声ファイルへの依存ゼロ。通信なしでレーザー発射音、爆発音、正解チャイム、BGMを即座に再生
   - ミュート（消音）切り替え機能つき

6. **学習・復習サポート**
   - クリアまたはゲームオーバー時に、出題された漢字・読み・意味を一覧で復習可能
   - 結果画面で現在の「漢字の部屋」進捗（例：〇/1026字）も表示
