# ファイブツアーズJET 漢字バトル 🚀✨

フジテレビ系人気番組「ネプリーグ」の「ファイブツアーズジェット」をオマージュした、小学校で学習する漢字を楽しく学べるWebタイピング・知育ゲーム（MVP）です。

👉 **ゲームプレイ（GitHub Pages）**: [https://fumiyan717.github.io/sisaku/](https://fumiyan717.github.io/sisaku/)

---

## 🎮 ゲームの特徴

1. **ファイブツアーズジェット風のSF演出**
   - 宇宙空間をハイスピードで進むジェット機（コックピット視点）
   - 迫り来るターゲットに表示される漢字の「よみ（ひらがな）」を入力
   - 正解するとレーザービーム発射＆派手な大爆発！
   - クルー（搭乗員5人＝ライフ）制。時間切れで1人ずつ撃墜！

2. **小学校1年生〜6年生の漢字配当**
   - 低学年（1・2年生）、中学年（3・4年生）、高学年（5・6年生）、FINAL最難関レベルを網羅
   - 「全ステージ挑戦モード」「低学年ツアー」「中学年ツアー」「高学年・難関ツアー」を選択可能

3. **マルチデバイス・小学生対応**
   - **PCキーボード**: IME入力（ひらがな）およびローマ字直接入力（例: `aozora` → `あおぞら`）に自動対応
   - **タブレット / スマートフォン**: 画面下の50音ソフトキーボード（濁点・半濁点・小文字変換対応）でタップ操作可能

4. **ピュアWeb Audio APIサウンド**
   - 外部音声ファイルへの依存ゼロ。通信なしでレーザー発射音、爆発音、正解チャイム、BGMを即座に再生
   - ミュート（消音）切り替え機能つき

5. **学習・復習サポート**
   - クリアまたはゲームオーバー時に、出題された漢字・読み・意味を一覧で復習可能
