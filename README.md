# ファイブツアーズJET 漢字バトル 🚀✨

フジテレビ系人気番組「ネプリーグ」の「ファイブツアーズジェット」をオマージュした、小学校で学習する漢字を楽しく学べるWebタイピング・知育ゲーム（MVP）です。

👉 **ゲームプレイ（GitHub Pages）**: [https://fumiyan717.github.io/sisaku/](https://fumiyan717.github.io/sisaku/)

---

## 🎮 ゲームの特徴

1. **ファイブツアーズジェット風のSF演出**
   - 宇宙空間をハイスピードで進むジェット機（コックピット視点）
   - 迫り来るターゲットに表示される漢字の「よみ（ひらがな）」を入力
   - 正解するとレーザービーム発射＆派手な大爆発！
   - クルー（搭乗員5人＝ライフ）制。時間切れで1人ずつ撃墜！

2. **学年別コース制（1年生〜6年生＋全学年チャレンジ）**
   - **１年生コース**: 文部科学省学習指導要領配当の音読み・訓読みに100%完全準拠した基本の読み・送り仮名・数の数え方（全70問へ大幅拡充！）
   - **２年生コース**: 第2学年配当（160字）の漢字を使った日常の言葉（全40問収録）
   - **３年生コース**: 第3学年配当（200字）の漢字を使った身近な熟語（全40問収録）
   - **４年生コース**: 第4学年配当（202字）の漢字を使った発展の言葉（全40問収録）
   - **５年生コース**: 第5学年配当（193字）の漢字を使った少し高度な熟語（全40問収録）
   - **６年生コース**: 第6学年配当（191字）の漢字を使った総仕上げレベル（全40問収録）
   - **全学年チャレンジ**: 1年生〜6年生の全範囲からバランス良く出題される完全制覇ツアー
   - ※各学年で習っていない未習漢字が出ないよう、学習指導要領配当漢字に厳密に準拠！

3. **小学生にやさしい操作・入力システム**
   - **文字ブロック入力パネル**: 候補の平仮名10文字からポンポン押して直感解答（濁点・半濁点・促音・拗音も直接タップ可能）
   - **50音ソフトキーボード**: タブ切り替えで自由入力も可能
   - **マス目表示**: 何文字の読みか一目で分かるマス目スロット
   - **安心の制限時間30秒**: ゆっくり考えて答えられるゆとり設計
   - **PCキーボード完全対応**: `jyu`（じゅ）、`zyu`、`tyu`（ちゅ）、`syo`（しょ）、`kya`（きゃ）などの拗音・促音（っ）・撥音（ん）や、IME日本語入力に完全対応

4. **新機能「漢字の部屋（学習進捗コレクション＆3段階マスター定着度）」🏛️✨**
   - 小学校6年間で学習する配当漢字全1,026字を学年ごとに一覧表示！
   - **3段階マスター定着度**:
     - 🥉 **銅ランク**: 1〜2回正解（クリア済み）
     - 🥈 **銀ランク**: 3〜4回正解（定着してきた漢字）
     - 🥇 **金ランク**: 5回以上正解（完全マスター！金ピカのオーラアニメーション）
   - **漢字詳細カード（全学年タップ表示）**: 漢字をタップすると音読み・訓読み・学年・正解回数・例文を即座にポップアップ表示！
   - **学年別 音読み・訓読み一覧表**: 1年生〜6年生の各学年タブごとに、公式音訓一覧表（表形式）をモーダル内でいつでも閲覧可能！
   - 学年別・全体の進捗バーで「覚えた漢字の数と割合」を一目で確認可能
   - 児童一人ひとりの端末の **ローカルストレージ（localStorage）** に進捗データを自動蓄積・永続化

5. **ホーム画面の利便性向上 🏠⚡**
   - **学年進捗バッジ & ワンタップ「即発進」**: 各学年カードに現在の進捗率（例: `32/80字 40%`）を表示。「即発進」ボタンでモード選択の手間なく即プレイ可能
   - **低学年向けルビ表記**: 漢字が読めない児童でも迷わず選べるよう、学年表示等にひらがなルビを完備
   - **「きょうの特訓」デイリーミッション**: 毎日全学年混合で10問ランダム出題。初回クリアでボーナスEXP（+100EXP）獲得
   - **「にがて特訓」モード**: 過去に間違えた漢字だけを集中的に出題
   - **クイックナビゲーションバー**: ホーム画面下部から「あそびかた」「機体カスタム」「漢字の部屋」へいつでもワンタップで移動可能

6. **児童の学習効果を高める仕組み 📚🎯**
   - **漢字の部屋で学べる用例・例文解説**: 漢字詳細カードを開くと、その漢字を使った身近な例文・用例が表示され、音訓や語彙の定着をサポート（※問題出題中のネタバレを防ぐため、漢字の部屋でじっくり学習できる設計に最適化）
   - **タイムアウト時のワンポイント解説**: 時間切れになった際、HUDに正解の読みとアドバイス（例:「『日』は『ひ』『ニチ』と読むよ！」）を表示
   - **にがて漢字 自動リピート＆リベンジ機能**: 間違えた漢字を自動記憶し、通常モードでも優先的にブレンド出題。さらにリザルト画面に「にがてリベンジ！」ボタンを設置し、間違えた漢字をその場ですぐに再挑戦可能
   - **安心の途中帰還（「🏠 メニュー」ボタン）**: 「間違えてやる気がなくなってしまった」「やり直したい」という児童の気持ちに寄り添い、ゲームプレイ中いつでもメニューへ戻れるボタンを完備。途中でやめた場合は、そこまでの解答データは保存されず【未学習扱い】のまま破棄されるため、子どもの自己肯定感やモチベーションを守ります。誤タップ防止の確認モーダルつき。

7. **児童のやる気を継続させる工夫（ゲーミフィケーション） 🎮🎖️**
   - **連続ログイン（ストリーク）記録**: 毎日プレイすることで「🔥 3日連続」のように記録され、毎日の学習習慣化を後押し
   - **EXP（経験値）＆ 称号昇格システム**: 問題正解やクリアでEXPを獲得。みならいパイロットから最高位「漢字マスター提督」まで全8段階の階級がアップ
   - **コンボ演出 & スピードボーナス**: 連続正解でコンボカットイン＆ピッチ上昇サウンド。5秒以内の即答で「⚡ スピードボーナス（+30点）」獲得
   - **機体＆レーザーのカラーカスタマイズ**:
     - 機体カラー: ブルージェット、レッドコメット、エメラルドウイング、ゴールドフェニックス、ダークステルス
     - レーザーカラー: コズミックシアン、プラズマレッド、ネオングリーン、ソーラーゴールド、ハイパーパープル
     - 選択したカラーがゲーム中の自機とレーザー描画に即時反映
   - **「がんばり賞状（認定証）」発行機能 📜🖨️**:
     - 学年クリア時や漢字の部屋からいつでも表彰状を発行可能
     - 児童自身の名前を入力可能
     - ブラウザの印刷機能（`window.print()`）に対応し、A4用紙やPDFとしてそのまま綺麗に印刷・保存可能

8. **ピュアWeb Audio APIサウンド**
   - 外部音声ファイルへの依存ゼロ。通信なしでレーザー発射音、爆発音、正解チャイム、コンボ音、ランクアップファンファーレ、BGMを即座に再生
   - ミュート（消音）切り替え機能つき

9. **学習・復習サポート**
   - クリアまたはゲームオーバー時に、出題された漢字・読み・意味を一覧で復習可能
   - 結果画面で現在の「漢字の部屋」進捗（例：〇/1026字）も表示
